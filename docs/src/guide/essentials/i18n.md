# Legacy Text Migration

::: warning Legacy text system removed (as of v7.0.0)
7.0 uses only the `Messages` text system; it does not read, modify, delete or automatically convert 6.x language files.
:::

| 6.x | 7.0 |
| --- | --- |
| `i18n("original sentence")` | Inject `Messages` and call `messages.send(sender, messages.key("a.b"), args…)`. |
| `String.format(i18n(k), x)` | Use a named tag such as `<name>` in the template and pass `Arg.string("name", x)`, or `Arg.number` for a number. |
| `getLanguageCode()` | Inject `LocaleResolver` and call `fallback()` for the server’s fallback `Locale`. Use `Messages` directly for per-recipient text. |
| `supported()`, `@I18n`, `@UltiToolsModule(i18n = …)` | Remove the override or declaration and ship `messages/<locale>.yml`. |
| `lang/<code>.json`, `.yml` or `.yaml` | Ship `messages/<code>.yml` and replace sentence keys with dotted keys. |
| `MessageUtils.sendMessage(...)` | Use `Messages.send(...)`; use `Text.literal(component)` for an existing Adventure component. |
| `@ConfigEntry(comment = "{k}")` | Define `k` in the module’s `messages/<locale>.yml`. See [Module annotation text](/guide/essentials/messages#module-annotation-text). |

If legacy directories are found at startup, the framework logs one INFO line. It checks `plugins/UltiTools/lang` and `plugins/UltiTools/pluginConfig/<module>/lang` without recursing, lists up to 20 paths and counts the rest. Copy any revised translations into [override files](/guide/essentials/messages#operator-overrides). See [Module Versioning](/guide/advanced/module-versioning#modules-6x-to-7) for the full upgrade checklist and [Messages and Languages](/guide/essentials/messages) for the new API.
