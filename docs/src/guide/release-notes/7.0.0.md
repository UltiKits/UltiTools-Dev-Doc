# UltiTools-API 7.0.0 Release Notes

7.0.0 has not been released. This page will be updated as development continues.

## Runtime Requirements

As of v7.0.0, the target is Paper 26.3 (build 258) with Java 25. Older Paper versions and plain Spigot are not supported targets; see [Older Servers](/guide/advanced/older-servers) for the historical 6.x guidance.

## Module Admission

As of v7.0.0, a module's root `plugin.yml` must declare an integer `api-version` from `700` through the running framework's API level. Rebuild 6.x modules against 7.0 and the target Paper version; changing the declaration alone does not make a 6.x JAR compatible. See [Module Versioning](/guide/advanced/module-versioning#modules-6x-to-7).

## Commands

As of v7.0.0, UltiTools compiles annotation-based commands into Brigadier trees and registers them through Paper's command lifecycle event. It no longer registers them by editing Bukkit's private command map. See [Command Executor](/guide/essentials/cmd-executor).

## Text and Languages

As of v7.0.0, `Messages` and the `messages/<locale>.yml` catalogues are the only text system. Legacy `lang/` files are not imported; see [Messages and Languages](/guide/essentials/messages) and [Legacy Text Migration](/guide/essentials/i18n).

## Configuration

As of v7.0.0, translations for `@ConfigEntry` comment keys come from the module’s `messages/<locale>.yml` catalogues. `/ul reload` reloads configuration, not classes; changing a JAR requires a full server restart. See [Config File](/guide/essentials/config-file).

## Data and Stored Items

As of v7.0.0, `ItemStackUtils` writes item arrays using Paper's item-byte format encoded as Base64. It still reads the old Bukkit object-stream format written by 6.x `ItemStackUtils`, but 6.x readers do not understand the new format. See [Items and Item Storage](/guide/essentials/items).

## Start-up and Bootstrap Content

As of v7.0.0, Paper runs the framework bootstrap before worlds load, while IoC and normal enable hooks run during plugin enable. An optional module bootstrap hook can declare custom enchantments, item and enchantment tags, and data packs bundled in the module JAR. See [Start-up Phases](/guide/advanced/startup-phases#bootstrap-content).

## Panel and UltiCloud

As of v7.0.0, module installs, updates and uninstalls are queued until the next restart. On a server connected to UltiCloud, the server owner can view pending changes in the panel and revoke eligible entries individually. See [Panel Integration](/guide/advanced/panel-integration).

## Removed Public APIs

As of v7.0.0, several 6.x public APIs are removed, including legacy command, text and GUI APIs; see the [upgrade guide](/guide/advanced/upgrading-to-7) and the framework's [compatibility policy and removal lists][compatibility policy].

## Upgrade Guide

Module authors and external plugin authors can start with [Upgrading from 6.x to 7.0](/guide/advanced/upgrading-to-7). Follow the checklist before testing on the new Paper baseline.

[compatibility policy]: https://github.com/UltiKits/UltiTools-Reborn/blob/main/COMPATIBILITY.md
