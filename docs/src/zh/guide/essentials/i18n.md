# 旧文本体系迁移

::: warning 旧文本体系已移除（自 v7.0.0 起）
7.0 只使用 `Messages` 文本体系，不读取、修改、删除或自动转换 6.x 的旧语言文件。
:::

| 6.x | 7.0 |
| --- | --- |
| `i18n("original sentence")` | 注入 `Messages`，调用 `messages.send(sender, messages.key("a.b"), args…)`。 |
| `String.format(i18n(k), x)` | 在消息模板中写 `<name>` 等命名标签，传入 `Arg.string("name", x)`；数值用 `Arg.number`。 |
| `getLanguageCode()` | 需要服务器后备语言时注入 `LocaleResolver` 并调用 `fallback()`；给收件人发消息时直接用 `Messages`。 |
| `supported()`、`@I18n`、`@UltiToolsModule(i18n = …)` | 移除覆盖或声明，随模块打包 `messages/<locale>.yml`。 |
| `lang/<code>.json`、`.yml`、`.yaml` | 随包提供 `messages/<code>.yml`，用点分键替代句子键。 |
| `MessageUtils.sendMessage(...)` | 改用 `Messages.send(...)`；已有的 Adventure 组件用 `Text.literal(component)`。 |
| `@ConfigEntry(comment = "{k}")` | 在模块的 `messages/<locale>.yml` 中定义 `k`。见[配置注释、命令描述与补全提示](/zh/guide/essentials/messages#module-annotation-text)。 |

启动时若发现旧目录，框架只记录一条 INFO：检查 `plugins/UltiTools/lang` 和 `plugins/UltiTools/pluginConfig/<模块名>/lang`，不递归，最多列出 20 个路径，其余只报数量。请将修改过的翻译手动写入[覆盖文件](/zh/guide/essentials/messages#operator-overrides)。完整迁移步骤见[模块版本规范](/zh/guide/advanced/module-versioning#modules-6x-to-7)，新 API 见[消息与语言](/zh/guide/essentials/messages)。
