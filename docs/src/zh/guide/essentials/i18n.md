# 旧文本体系迁移

::: warning 旧文本体系已移除（自 v7.0.0 起）
7.0 只使用 `Messages` 文本体系，不读取、修改、删除或自动转换 6.x 的旧语言文件。
:::

| 6.x | 7.0 |
| --- | --- |
| `i18n("original sentence")` | 注入 `Messages`，调用 `messages.send(sender, messages.key("a.b"), args…)`。 |
| `String.format(i18n(k), x)` | 在消息模板中写 `<name>` 等命名标签，传入 `Arg.string("name", x)`；数值用 `Arg.number`。 |
| `getLanguageCode()` | 需要服务器后备语言时注入 `LocaleResolver` 并调用 `fallback()`；给收件人发消息时直接用 `Messages`。 |
| `supported()`、`@I18n`、`@UltiToolsModule(i18n = …)` | 移除覆盖或声明，随模块打包 `messages/<locale>.yml`。 |
| `lang/<code>.json`、`.yml`、`.yaml` | 随包提供 `messages/<code>.yml`，用点分键替代句子键。 |
| `MessageUtils.sendMessage(...)` | 改用 `Messages.send(...)`；已有的 Adventure 组件用 `Text.literal(component)`。 |
| `@ConfigEntry(comment = "{k}")` | 在模块的 `messages/<locale>.yml` 中定义 `k`。若措辞有变，把 6.x 的旧文字列入 `@ConfigEntry(previousComments = …)`，框架才能识别并替换旧注释。无法识别的文字（包括只与 6.x 自定义 `lang/` 文件匹配的文字）原样保留为服主内容。见[配置注释、命令描述与补全提示](/zh/guide/essentials/messages#module-annotation-text)。 |

## 已删除的类型和入口 {#removed-text-apis}

- **发送消息：** `UltiToolsPlugin#i18n(String)`、`UltiToolsPlugin#i18n(String, String)`、`UltiTools#i18n(String)`、`UltiTools#i18n(String, String)` 和 `MessageUtils`。按上表改用 `Messages`。
- **读取语言：** `UltiToolsPlugin#getLanguageCode()`、`UltiToolsPlugin#getConfiguredLanguage()`、`UltiToolsPlugin#getLanguage()`、`UltiTools#getLanguage()` 和 `Language`。需要服务器后备语言时用 `LocaleResolver#fallback()`；按收件人发送消息时用 `Messages`。
- **声明语言：** `Localized`（包括 `Localized#supported()`）、`UltiToolsPlugin#supported()`、`UltiTools#supported()`、`@I18n` 和 `@UltiToolsModule` 的 `i18n` 属性。删除覆盖和声明，以及对 `supported()` 的调用（已无法通过编译），改为随模块打包消息目录。
- **旧工具：** `UltiToolsPlugin#overrideLostPlaceholders(...)`、`FrameworkText` 和 `OfficialLanguageFiles`。改用模板的命名参数，不再修补旧占位符；用消息目录和覆盖文件替代旧语言文件的管理方式。

## 已有语言文件

7.0 不再从模块 JAR 读取或解出旧 `lang/` 资源。`language: zh-myserver` 仍会选择基础语言 `zh`，但不会加载旧自定义文件。

启动时若发现旧目录，框架只记录一条 INFO：检查 `plugins/UltiTools/lang` 和 `plugins/UltiTools/pluginConfig/<模块名>/lang`，不递归，最多列出 20 个路径，其余只报数量。请将修改过的翻译手动写入[覆盖文件](/zh/guide/essentials/messages#operator-overrides)。完整迁移步骤见[模块版本规范](/zh/guide/advanced/module-versioning#modules-6x-to-7)，新 API 见[消息与语言](/zh/guide/essentials/messages)。
